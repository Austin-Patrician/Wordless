# Content Web Research

Build a compact, traceable evidence packet for the content team. This skill uses only the web search and crawling connector tools exposed in the current session; it does not require `research_snapshot`, `research_submit_dimension`, or other data-analysis research tools.

## Workflow

1. Restate the audience, content goal, geography, time range, and claims that need external support.
2. Search narrowly for each material question. Prefer primary, official, regulatory, academic, filing, or directly accountable sources.
3. Open or crawl the strongest results when a search snippet is insufficient.
4. Cross-check decision-critical claims with an independent source. Do not treat several pages repeating the same origin as independent confirmation.
5. Record the source title, publisher, URL, publication or update date when available, and the exact fact it supports.
6. Separate verified facts, reasonable interpretation, and unresolved uncertainty.
7. Hand the writer a concise editorial brief rather than a raw search transcript.

## Safety And Permissions

- Use read-only search and retrieval operations whenever possible.
- If a connector operation is not explicitly read-only, wait for approval instead of attempting an alternative that bypasses it.
- Never publish, upload, modify remote data, submit forms, or change workspace files.
- Do not invent a source, URL, quotation, statistic, or publication date.
- If no suitable web connector is available, return a clear blocker and continue with only the evidence supplied by the user.

## Handoff

Return:

- the recommended angle and audience promise;
- a short outline and evidence requirements for each section;
- a source list with URLs and supported claims;
- conflicts, stale information, and facts that still need verification;
- tone, constraints, and acceptance criteria for the writer.
