# Documentation screenshots

Documentation screenshots use PNG. Capture the full desktop window at a consistent aspect ratio, keep realistic sample data, and redact API keys, OAuth tokens, email addresses, personal paths, and private workspace content.

Screenshots currently live under `public/images/`. When replacing a capture, keep its existing filename so the Chinese and English pages continue sharing the same source.
