## 工作区与本地优先

每个会话绑定一个工作区。文件引用、工作空间文件和默认访问都以该目录为边界。模型请求会发送完成任务所需的提示词与上下文；本地文件不会因为安装 Wordless 自动上传到 Wordless 服务器。

## 对话中的引用

<Tabs>
  <TabItem label="@ 文件与文件夹">
    输入 `@` 搜索当前工作区中的文件或文件夹。列表遵循 `.gitignore`；用 ↑/↓ 选择，回车插入引用标记，Esc 关闭。插入后可继续输入，不会立即发送。
  </TabItem>
  <TabItem label="$ 技能">
    输入 `$` 搜索已启用技能。引用标记会使用对应技能的图标；回车只插入，发送仍由你确认。也可以从对话输入区的 `+` 菜单选择。技能来自[技能与 MCP](/docs/skills-mcp/) 的已安装列表，包括从「发现」安装的条目。
  </TabItem>
  <TabItem label="! 任务">
    输入 `!` 搜索任务看板中「待处理」和「进行中」的任务。回车把标题、详情和预期结果插入输入区，不会执行该任务，也不会改看板状态。完整执行流程见[任务看板](/docs/tasks/)。
  </TabItem>
</Tabs>

引用标记是结构化上下文，不等同于普通文本路径。删除时将指针移到标记上，通过替换前置图标的删除按钮移除。

## 审批模式与访问级别

- **手动审批：** 默认模式，每个需审批工具由用户明确允许。
- **本次自动审批：** 只对当前会话的普通风险操作自动允许；高风险审批出现后自动审批失效，并要求手动决定。
- **默认访问：** 文件操作限制在当前工作区。
- **完全访问：** 扩大访问范围，适合明确知道目标路径和影响的任务。
- **一次性提权：** 当工具因工作区边界失败时，只允许该次指定操作，随后仍保持默认访问。

<ApprovalCheckpoint risk="high" title="高风险操作永远需要重新确认">
自动审批不是永久授权。删除、敏感路径、危险命令等高风险操作应显示明确目标，且不能沿用之前的会话自动批准状态。
</ApprovalCheckpoint>

## 会话、压缩与定位

Wordless 把每次对话保存为本地会话记录。如何在侧边栏查找、置顶、重命名和删除，见[对话管理](/docs/sessions/)。

上下文较长时会压缩较早对话以腾出模型上下文，但不会把“压缩完成”误当成新的压缩任务。右上角 **搜索消息** 只高亮匹配关键词，并在虚拟消息列表中定位到对应消息。

对话输入区空白且未处于 `@` / `$` / `!` 选择时，↑ 可调出上一条用户消息，↓ 可向较新的用户消息移动。编辑过历史内容后，Wordless 会保留当前草稿。

## 模型与思考深度

先点击模型即可直接选中。只有当前选中的模型会展示其思考深度二级选项。未手动指定时默认「中」；提供商或模型不支持该能力时不显示该选项。
