## 开源项目与致谢

Wordless 复用了并适配了多个优秀的开源项目：Agent 内核来自 [Pi Agent Harness](https://github.com/earendil-works/pi)，文档站基于 [Astro Starlight](https://github.com/withastro/starlight)，桌面容器使用 [Electron](https://github.com/electron/electron)，首页 3D 场景使用 [Three.js](https://github.com/mrdoob/three.js)。二次分发时请保留各项目的许可证和原始仓库地址。
