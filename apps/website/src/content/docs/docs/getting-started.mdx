<Prerequisites>
- 已按照[安装 Wordless](/docs/installation/)完成安装，并能看到工作台
- 一个受支持模型提供商的 API Key 或本地模型配置
- 一个包含 `README.md` 的非敏感示例文件夹
</Prerequisites>

## 1. 认识首次启动界面

启动 Wordless 后选择 **General Work**。需要读取本地文件时再选择工作区；不涉及文件的问答可以暂时跳过工作区。

<ScreenshotFrame src="/images/Wordless%20first%20launch.png" alt="Wordless 首次启动工作台" caption="首次启动工作台：General Work 适合完成通用资料整理、写作和文件理解任务。" />

## 2. 配置并选择模型

<Steps>
1. 打开 **Settings → Models**。
2. 选择模型提供商，填写 API Key；自定义提供商还需要正确填写 Base URL、Provider ID 和模型配置。
3. 保存配置，并在 **Enabled models** 中启用希望出现在 Composer 的模型。
4. 回到 Composer，点击模型选择器并直接选择该模型。
5. 支持思考深度的模型在未手动指定时默认使用 `medium`。
</Steps>

API Key 只应填写在设置界面，不要写进提示词、项目文件或截图。自定义模型字段的完整解释和示例见[模型配置](/docs/models/)。

<ScreenshotFrame src="/images/model%20setup.png" alt="Wordless 模型提供商设置" caption="填写 Provider 凭据、保存配置，并只启用希望在 Composer 中使用的模型。" />

## 3. 创建工作区会话

<Steps>
1. 创建新会话并选择 **General Work**。
2. 点击工作区选择器，选择包含 `README.md` 的示例文件夹。
3. 确认右侧 Workspace Files 能看到该文件。工作区决定 Default Access 下 Agent 可以读取和修改的边界。
4. 如果提示 `The selected workspace is unavailable`，重新选择当前用户可读取、尚未被移动或删除的文件夹。
</Steps>

第一次任务建议使用不含密钥、客户资料或个人信息的小型项目。

## 4. 引用文件并发送任务

在 Composer 输入 `@`，继续输入 `README` 过滤文件。使用 ↑/↓ 选择目标，按 Enter 只会把引用 token 插入输入区，不会立即发送消息；补充任务说明后再发送。

<PromptBlock>
请阅读 @README.md，总结这个项目的用途、启动步骤与目录结构。不要修改文件；结论中引用对应的文件位置，并指出信息不足的部分。
</PromptBlock>

<ApprovalCheckpoint>
纯读取通常可在默认访问范围内执行。命令执行、写文件或访问工作区外路径时会显示审批卡；先检查工具名称、目标路径与参数，再选择允许或拒绝。
</ApprovalCheckpoint>

## 5. 核对结果

不要只判断回答是否“看起来合理”。展开工具卡确认执行状态，打开 `README.md`，逐项核对用途、启动命令和目录说明是否有原文依据。

<ExpectedResult>
会话中出现基于 `README.md` 的结构化总结；工具卡显示 running、success 或 failed 状态，且任务没有修改任何文件。
</ExpectedResult>

## 状态与恢复

- **Running：** Agent 仍在生成或执行工具，不要重复发送同一任务。
- **Awaiting approval：** 需要在会话中的审批卡做出选择。
- **Failed：** 展开工具结果，复制原始错误文本后按[故障排查](/docs/troubleshooting/)处理。
- **Organizing earlier conversation：** 正在压缩较早上下文；完成后会继续当前任务。
