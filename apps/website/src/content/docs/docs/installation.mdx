## 下载地址

安装包只通过官方下载页分发，下载链与网站首页的[下载](/#download)相同，由 `download.wordless.20250230.xyz` 提供文件：

- **打开下载页：** [wordless.20250230.xyz/#download](/#download)

页面会列出当前版本对应的 Apple Silicon、Intel Mac 和 Windows x64 安装包。点对应条目即可下载，不要从聊天、网盘或其他网站转发的链接安装。

## 先确认应该下载哪个文件

| 你的设备 | 在哪里确认 | 应下载的文件 |
| --- | --- | --- |
| Apple Silicon Mac（M1、M2、M3、M4 等） |  → **关于本机**，芯片显示 Apple M 系列 | `Wordless-<版本>-mac-arm64.dmg` |
| Intel Mac |  → **关于本机**，处理器显示 Intel | `Wordless-<版本>-mac-x64.dmg` |
| 常见 Windows 10/11 电脑 | **设置 → 系统 → 系统信息**，系统类型显示 x64 | `Wordless-<版本>-win-x64.exe` |
| Windows ARM 设备 | 系统类型显示 ARM64 | 当前没有原生安装包，请勿安装 x64 版本 |

macOS 当前要求 **macOS 13 或更高版本**。Windows 当前只提供 **x64** 安装包。版本号会随发布变化，选择时看文件名末尾的平台和架构。

## 安装步骤

<Tabs>
  <TabItem label="macOS">
    <Steps>
    1. 根据上表从官方下载页下载 `mac-arm64.dmg` 或 `mac-x64.dmg`。
    2. 双击下载的 DMG，等待安装窗口打开。
    3. 将 **Wordless** 图标拖入 **应用程序** 文件夹。
    4. 等待复制完成，弹出 DMG，然后从“应用程序”打开 Wordless。不要一直从 DMG 窗口运行应用。
    5. 内测包未经过 Apple Developer ID 公证时，macOS 可能提示无法验证开发者。回到 Finder，在“应用程序”中按住 Control 点击 Wordless，选择 **打开**；或进入 **系统设置 → 隐私与安全性**，确认刚刚被阻止的 Wordless 后选择 **仍要打开**。
    6. 仅当安装包来自官方下载页或 `download.wordless.20250230.xyz` 时确认打开。不要关闭 Gatekeeper，也不要全局降低 macOS 安全设置。
    </Steps>
  </TabItem>
  <TabItem label="Windows">
    <Steps>
    1. 从官方下载页下载 `Wordless-<版本>-win-x64.exe`。
    2. 双击安装程序，按向导选择安装位置并完成安装。
    3. 如果 SmartScreen 显示“Windows 已保护你的电脑”，先确认文件来自官方下载页或 `download.wordless.20250230.xyz`，再选择 **更多信息 → 仍要运行**。
    4. 从开始菜单或桌面快捷方式启动 Wordless。
    </Steps>
  </TabItem>
</Tabs>

<Prerequisites title="下载前的安全检查">
- 浏览器地址应为 `wordless.20250230.xyz` 或实际文件来自 `download.wordless.20250230.xyz`
- 下载页应显示明确版本号；不要使用来源不明的安装包
- 升级已有版本前先退出 Wordless；你的工作区文件不会被安装程序删除
</Prerequisites>

## 验证安装

启动成功后应看到 Wordless 工作台，而不是持续空白窗口。打开 **设置 → 关于与更新**，确认应用名称和版本号与刚下载的包一致。

<ExpectedResult>Wordless 已复制到 macOS 的“应用程序”或安装到 Windows，能够正常打开并显示工作台。下一步先[配置模型](/docs/models/)，再[完成首次任务](/docs/getting-started/)。</ExpectedResult>

## 安装问题

- **macOS 提示无法验证开发者：** 使用上面的 Control 点击“打开”或“隐私与安全性 → 仍要打开”，这是当前未公证内测包的预期行为。
- **macOS 提示应用已损坏：** 删除当前应用和 DMG，从官方下载页重新下载与芯片匹配的文件；不要直接绕过校验。
- **打开后是白屏：** 先确认下载的是最新版本；若仍存在，记录系统版本、芯片、Wordless 版本并在 [GitHub Issues](https://github.com/Austin-Patrician/Wordless/issues) 提交问题。
- **Windows 安装程序无法运行：** 确认系统类型为 x64，并重新从官方下载页获取 `.exe`。
- **需要升级：** 打开 [官方下载页](/#download)，退出当前版本后安装新包。未签名的 macOS 内测版可能需要手动替换「应用程序」中的旧版本。
