## 常用设置

- **模型：** 提供商、Base URL、模型、思考深度。思考深度只显示在当前选中的支持模型下，默认「中」。
- **个性化：** 主题、语言与界面密度。
- **数据与隐私：** 权限、请求数据、Google 登录与可选云同步。
- **关于与更新：** 项目版本、更新说明和手动检查。

## 更新流程

<Steps>
1. 打开 **设置 → 关于与更新**，点击检查更新。
2. 阅读当前版本的功能变化，选择稍后提醒或下载。
3. 下载完成后点击 **重启并安装**；应用会退出并由更新程序安装。
4. macOS 未签名版本可能无法通过系统代码签名验证，此时按[快速开始](/docs/installation/)从官方下载页手动安装匹配架构的包。
</Steps>

<ScreenshotFrame src="/images/settings/settings-update.png" alt="关于与更新：当前版本和发布历史" caption="关于与更新展示当前版本与设备架构、手动检查入口和可展开的发布历史。" />

更新失败不会删除当前版本。优先检查网络、安装包完整性和磁盘空间；保留现有安装，改从[官方下载页](/#download)手动安装。
