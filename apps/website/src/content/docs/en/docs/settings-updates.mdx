Models, thinking depth, appearance, language, notifications, Data & Privacy, Google account, and About & Updates live in Settings. Thinking depth appears only for the selected model and defaults to `medium` when supported.

<Steps>
1. Open **Settings → About & Updates** and check for a release.
2. Read the version notes, then choose to defer or download; updates are optional.
3. When ready, click **Restart & Install**.
4. On unsigned macOS builds, code-signature validation may require downloading the matching package from the [official download page](/#download) and installing it manually.
</Steps>

<ScreenshotFrame src="/images/settings/settings-update.png" alt="About & Updates version and release history" caption="About & Updates shows the current version and architecture, manual check action, and expandable release history." />

A failed update leaves the current installation in place. Check network, package integrity, and disk space before installing again from the [official download page](/#download).
