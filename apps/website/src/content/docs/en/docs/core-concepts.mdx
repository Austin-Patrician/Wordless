## Workspace and local-first behavior

Each session is bound to a workspace. File references, Workspace Files, and Default Access use that directory as their boundary. Wordless sends the task and necessary context to the model provider you selected; local files are not uploaded to Wordless automatically.

## Composer references

<Tabs>
  <TabItem label="@ files and folders">Type `@` to search workspace files, filtered by `.gitignore` when present. Use ↑/↓ and Enter to insert a token; Esc closes the list.</TabItem>
  <TabItem label="$ Skills">Type `$` to search enabled Skills. Enter inserts the Skill token; sending remains a separate action. The `+` menu offers the same selection. Skills come from the Installed list in [Skills & MCP](/en/docs/skills-mcp/), including entries installed from Discover.</TabItem>
  <TabItem label="! tasks">Type `!` to search To do and In progress items on the task board. Enter inserts the title, details, and expected result; it does not run the task or change board status. See [Task board](/en/docs/tasks/) for execution.</TabItem>
</Tabs>

Tokens are structured context, not plain path text. Focusing a token replaces its leading icon with the remove action.

## Approvals and access

- **Manual approve** is the default: each tool requiring approval is explicitly allowed.
- **Auto-approve for this session** applies only to ordinary-risk actions in the current session. A high-risk card disables it and requires a manual decision.
- **Default Access** limits file operations to the workspace.
- **Full Access** expands the boundary and should be used only when the impact is understood.
- **One-time elevation** permits one named operation while keeping Default Access afterward.

<ApprovalCheckpoint risk="high" title="High-risk actions always require a fresh decision">Session auto-approval is not permanent authorization. Deletion, sensitive paths, and dangerous commands must be shown with an explicit target.</ApprovalCheckpoint>

## Sessions, search, and compaction

Wordless stores each conversation as a local session record. Finding, pinning, renaming, and deleting those records is covered in [Manage conversations](/en/docs/sessions/).

Long contexts may be compacted; that does not create a new user task. **Search messages** highlights the matching keyword and scrolls the virtual list to the exact message. With an empty Composer and no `@`/`$`/`!` picker, ↑ and ↓ move through user-message history.

## Models and thinking depth

Clicking a model selects it immediately. Only the selected model exposes its supported thinking-depth submenu. If you do not choose a value, `medium` is used; unsupported models do not show the control.
