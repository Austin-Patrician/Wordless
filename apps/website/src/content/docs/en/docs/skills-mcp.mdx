<Prerequisites>
- A trusted Skill or MCP source
- The service URL, OAuth configuration, or bearer token supplied by its owner
- A plan for which tools and permissions the connection should expose
</Prerequisites>

<Steps>
1. Open **Skills & MCP**, inspect the source, tools, and permission summary, then install or import the Skill.
2. Enable it and type `$` in Composer. Use ↑/↓ and Enter to insert its token; sending remains separate.
3. For custom MCP, choose a transport and enter only the required settings.
4. Test the connection and inspect the tool list before using it in a task.
5. Remove the local configuration when it is no longer trusted; revoke remote OAuth separately at the provider.
</Steps>

<Tabs>
  <TabItem label="stdio">Enter the command and arguments. Verify the binary exists and pass secrets through environment variables only when required.</TabItem>
  <TabItem label="Remote HTTP">Use HTTPS and prefer OAuth over long-lived bearer tokens. Never paste a token into a shared config or prompt.</TabItem>
</Tabs>
