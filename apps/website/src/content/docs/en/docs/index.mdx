## Open-source credits

Wordless adapts [Pi Agent Harness](https://github.com/earendil-works/pi) for its agent runtime, [Astro Starlight](https://github.com/withastro/starlight) for documentation, [Electron](https://github.com/electron/electron) for the desktop shell, and [Three.js](https://github.com/mrdoob/three.js) for the website’s 3D surface. Preserve each project’s license and upstream link when redistributing.
