## Download

Installers are distributed only from the official download page. The file links are the same ones used by [Download](/#download) on the website, served from `download.wordless.20250230.xyz`:

- **Open the download page:** [wordless.20250230.xyz/#download](/#download)

The page lists the current Apple Silicon, Intel Mac, and Windows x64 packages. Click the matching row to download. Do not install a copy forwarded through chat, a file host, or another website.

## Choose the correct package

| Your device | How to check | Download this file |
| --- | --- | --- |
| Apple Silicon Mac (M1, M2, M3, M4, and later) | Apple menu → **About This Mac** shows an Apple M-series chip | `Wordless-<version>-mac-arm64.dmg` |
| Intel Mac | Apple menu → **About This Mac** shows an Intel processor | `Wordless-<version>-mac-x64.dmg` |
| Typical Windows 10/11 PC | **Settings → System → About** shows an x64 system type | `Wordless-<version>-win-x64.exe` |
| Windows on ARM | System type shows ARM64 | No native package is currently available; do not install the x64 build |

macOS currently requires **macOS 13 or later**. Windows currently has an **x64-only** installer. The version number changes between releases; identify the package by the platform and architecture at the end of the filename.

## Install

<Tabs>
  <TabItem label="macOS">
    <Steps>
    1. From the official download page, download the `mac-arm64.dmg` or `mac-x64.dmg` identified above.
    2. Double-click the DMG and wait for its installation window to open.
    3. Drag **Wordless** into **Applications**.
    4. Wait for the copy to finish, eject the DMG, and open Wordless from Applications. Do not keep running it from the DMG window.
    5. Because test builds are not notarized with an Apple Developer ID, macOS may say it cannot verify the developer. In Finder, Control-click Wordless in Applications and choose **Open**; alternatively, use **System Settings → Privacy & Security → Open Anyway** for the blocked Wordless launch.
    6. Confirm this only for a package from the official download page or `download.wordless.20250230.xyz`. Do not disable Gatekeeper or globally lower macOS security.
    </Steps>
  </TabItem>
  <TabItem label="Windows">
    <Steps>
    1. From the official download page, download `Wordless-<version>-win-x64.exe`.
    2. Run the installer, choose an installation folder, and complete the wizard.
    3. If SmartScreen displays “Windows protected your PC,” first verify the official download page or `download.wordless.20250230.xyz`, then choose **More info → Run anyway**.
    4. Start Wordless from the Start menu or desktop shortcut.
    </Steps>
  </TabItem>
</Tabs>

<Prerequisites title="Safety check before installation">
- The browser should be on `wordless.20250230.xyz`, and the actual file should come from `download.wordless.20250230.xyz`
- The download page should show a clear version; do not use an installer from an unknown source
- Quit Wordless before upgrading; installation does not remove your workspace files
</Prerequisites>

## Verify the installation

A successful launch shows the Wordless workbench rather than a persistent blank window. Open **Settings → About & Updates** and verify that the version matches the package you just downloaded.

<ExpectedResult>Wordless is in Applications on macOS or installed on Windows, opens normally, and displays the workbench. Next, [configure a model](/en/docs/models/), then complete [your first task](/en/docs/getting-started/).</ExpectedResult>

## Installation problems

- **macOS cannot verify the developer:** use Control-click → Open or Privacy & Security → Open Anyway as described above. This is expected for the current unnotarized test build.
- **macOS says the app is damaged:** remove the app and DMG, then download the correct architecture from the official download page again. Do not bypass integrity checks.
- **The app opens to a blank window:** verify that you installed the latest package. If it persists, include the OS, chip, and Wordless versions in a [GitHub issue](https://github.com/Austin-Patrician/Wordless/issues).
- **The Windows installer does not run:** verify that the system type is x64 and download the `.exe` from the official download page again.
- **Upgrading:** open the [official download page](/#download), quit Wordless, and install the new package. Unsigned macOS test builds may require manually replacing the old app in Applications.
