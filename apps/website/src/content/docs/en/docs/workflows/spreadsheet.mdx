## Goal

Inspect data, create formulas or charts, and verify each change in the right workspace without damaging the original workbook. The sheet is not an attachment preview; it is the agent's interactive context.

## The worksheet is the context

When you select a contiguous range, Wordless records its sheet, locator, formulas, and values. Choose **Reference**, **Analyze**, **Formula**, **Chart**, or **Pivot**, then describe the goal in Composer. The agent does not have to guess what `A1:H500` means. After a tool succeeds, the preview refreshes and Changes plus quality checks remain in the same session.

<Steps>
1. Open the workbook and target sheet from Workspace Files; the right panel shows an interactive workbook preview.
2. Drag across the contiguous range you want to work on and inspect its locator, formula, and value details.
3. Choose **Reference**, **Analyze**, **Formula**, **Chart**, or **Pivot** from the selection actions.
4. The selection becomes a structured token in Composer. Add the goal, output location, and ranges that must remain untouched.
5. Request a quality scan or analysis plan first; review each approval card before a write.
6. Ask the agent to apply formulas, charts, or pivots in a copy of the workbook.
7. When the tool succeeds, the right preview refreshes immediately. Select another range and continue iterating.
8. Review Changes and quality checks, then recalculate and publish from Excel/WPS.
</Steps>

## End-to-end analysis flow

<Prerequisites>
- An `.xlsx`, `.xls`, `.csv`, or `.tsv` file in the workspace
- Known headers, date/number units, and a contiguous data range
- A read-only backup copy of the original workbook
</Prerequisites>

<Steps>
1. Open the target sheet and select a contiguous range; reference the whole workbook with `@` only when needed.
2. Run a quality scan for blanks, duplicates, outliers, mixed types, formula errors, and hidden rows.
3. Ask for an analysis plan that names the copy path, target sheet, and cell range.
4. Approve the write, then inspect number formats, formulas, and chart axes in the preview.
5. Review Changes and quality checks. Recalculate formula caches in Excel/WPS before saving.
</Steps>

<PromptBlock label="Copyable analysis prompt">Analyze @sales.xlsx Sheet1!A1:H500. Scan for blanks, duplicate orders, date anomalies, negative amounts, and type mismatches with row numbers. ## What is different in Wordless

Traditional workflows copy ranges between chat, Excel, and a terminal. Wordless keeps selection references, analysis, approval, live preview, change history, and quality checks in one thread. Workbook operations integrate [iOfficeAI/OfficeCLI](https://github.com/iOfficeAI/OfficeCLI); recalculate formula caches in Excel/WPS before final verification.

| Scenario | Action in Wordless | Verification |
| --- | --- | --- |
| Data quality audit | Select a range and choose Analyze | Every finding has a row and field |
| Monthly analysis | Choose Formula/Chart for the selected range and write to a copy | Original unchanged and chart source correct |
| Template report | Reference a sheet and choose Pivot | Sheets and formatting preserved, no recalculation errors |

Some spreadsheet libraries write formulas without recalculating cached values. Open and recalculate in Excel/WPS, save, and verify again before treating a preview as final.
