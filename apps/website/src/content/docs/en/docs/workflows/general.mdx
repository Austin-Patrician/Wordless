<Prerequisites>
- A configured model with General Work selected
- A workspace and source files are optional; without them the agent must ask for missing facts instead of inventing internal data
- A defined audience, format, and acceptance criteria
</Prerequisites>

<Steps>
1. State the outcome, format, audience, constraints, and acceptance criteria.
2. If a workspace exists, reference sources with `@`; otherwise require explicit assumptions and an input checklist.
3. Ask for a plan before execution; keep Manual approve for writes.
4. Review each approval card’s tool, target, and parameters.
5. Open the output and verify every claim against its cited source.
</Steps>

## What is different in Wordless

Instead of returning an opaque chat answer, Wordless keeps references, approvals, file writes, and success/failure states in one thread. Start with no context, then add `@` files, `$` Skills, and explicit approval constraints only when the task needs them.

## Practical scenarios

| Scenario | Input | Verifiable result |
| --- | --- | --- |
| No-context planning | A written goal without a workspace | Assumptions and missing inputs remain separate |
| Multi-file decision brief | `@` brief and notes folder | Every key conclusion cites a source path |
| Plan written to disk | Goal plus output path | A reviewed write with visible completion state |
